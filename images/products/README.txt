==============================================
FootwearHub - Product Image Folder
==============================================

Drop your product photos in this folder using
the exact filenames listed below.

Recommended size: 300 x 200 pixels (or any 3:2)
Recommended format: .jpg or .png

If a file is missing, the website will show a
grey "Shoe" placeholder automatically.

----------------------------------------------
PRODUCT FILENAMES
----------------------------------------------

1.  air-runner-pro.jpg        (Running)
2.  urban-sneaker-x.jpg       (Sneakers)
3.  classic-oxford.jpg        (Formal)
4.  hiking-trail-boots.jpg    (Boots)
5.  beach-slide-sandals.jpg   (Sandals)
6.  marathon-lite.jpg         (Running)
7.  retro-high-top.jpg        (Sneakers)
8.  leather-derby.jpg         (Formal)
9.  snow-winter-boots.jpg     (Boots)
10. sport-flip-flops.jpg      (Sandals)
11. cloudstep-trainer.jpg     (Running)
12. canvas-low-sneaker.jpg    (Sneakers)

----------------------------------------------
HOW TO ADD AN IMAGE
----------------------------------------------

1. Find or download a photo of the shoe.
2. Rename it to one of the filenames above.
3. Save it in this folder.
4. Refresh the website - done!

----------------------------------------------
WANT DIFFERENT FILENAMES?
----------------------------------------------

You can change the filename in:
  ecommerce-project/js/data.js
Just edit the "image" field for each product.
